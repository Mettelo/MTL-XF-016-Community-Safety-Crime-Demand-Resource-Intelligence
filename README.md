# MTL-XF-016 — Community Safety, Crime Demand & Resource Allocation Intelligence

**Mettelo Project Studio — Cross-Functional Delivery Series**

| Field | Detail |
|---|---|
| Client | Confidential Community Safety Partnership |
| Sector | Public Safety / Local Government / Policing |
| Duration | 8 weeks |
| Recommended team | 6–8 |
| Sponsor | Director of Community Safety |
| Engagement | Simulated confidential-client engagement |

The partnership has limited neighbourhood and prevention resources, but current reporting does not distinguish persistent demand, emerging crime categories, force-area variation and changes in recorded-crime patterns well enough to support targeted intervention.

**Commissioned decision:** Which crime-demand patterns and areas should receive the earliest multi-agency investigation or prevention attention, and what evidence should be monitored before resources are reallocated?

This is an end-to-end multidisciplinary engagement, not a dashboard-only exercise.

Start with the project, governance, data and submission documents in this repository. Each team creates its delivery repository under the **Mettelo GitHub organisation** and adds every team member using their individual GitHub account.
