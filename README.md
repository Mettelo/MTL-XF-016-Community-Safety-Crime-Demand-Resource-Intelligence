# MTL-XF-016 — Community Safety, Crime Demand & Resource Allocation Intelligence

**Mettelo Project Studio — Cross-Functional Delivery Series**

| Field | Detail |
|---|---|
| Project ID | MTL-XF-016 |
| Client | Confidential Community Safety Partnership |
| Sector | Public Safety / Local Government / Policing |
| Duration | 8 weeks |
| Recommended Team Size | 6–8 |
| Primary Sponsor | Director of Community Safety |

The partnership has limited neighbourhood and prevention resources, but current reporting does not distinguish persistent demand, emerging offence patterns, police-force-area variation and recording effects well enough to support targeted intervention.

**Decision to support:** Which crime-demand patterns and areas should receive the earliest multi-agency investigation or prevention attention, and what evidence should be monitored before resources are reallocated?

This is an end-to-end delivery engagement, not a dashboard-only exercise.
