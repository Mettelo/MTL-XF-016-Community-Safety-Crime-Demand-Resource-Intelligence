# Data Workspace

**Primary dataset:** Home Office Police Recorded Crime Open Data — Police Force Area tables, year ending March 2013 onwards  
**Publisher:** Home Office  
**Format:** ODS  
**Official source:** https://www.gov.uk/government/statistical-data-sets/police-recorded-crime-and-outcomes-open-data-tables

Use a frozen Mettelo cohort version/reference so the project remains reproducible if the publisher changes its site. Preserve raw data unchanged and record version/acquisition details in `SOURCE_REGISTER.md`.
