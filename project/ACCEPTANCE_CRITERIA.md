# Agreed Acceptance Criteria

1. **AC1:** All offence categories used in trend analysis are mapped to documented source definitions.
2. **AC2:** At least one methodology/recording continuity review is completed before interpreting long-term trend breaks.
3. **AC3:** Priority flags require persistence across more than one reporting period unless a documented exception is approved.
4. **AC4:** No area is labelled dangerous/high risk solely from raw recorded-crime volume.
5. **AC5:** At least five dashboard figures reconcile to the source table for selected offence/area periods.
6. **AC6:** Volume and percentage-change views are both provided to prevent small-base distortion.
7. **AC7:** Any denominator-based rate uses a documented compatible denominator and period.
8. **AC8:** A reviewer can reproduce the longitudinal trend table and priority-investigation outputs from the frozen source file.

## Sign-off Rule
Repository files existing is not enough. The panel must verify these criteria from evidence.

## Evidence Mapping
Map every criterion to requirement(s), artefact(s), test/reconciliation evidence, owner and status.
